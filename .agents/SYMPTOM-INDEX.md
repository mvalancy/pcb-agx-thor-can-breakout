# Symptom index

- Netlist parity, connector substitutions, clamp collision, STEP datum, KiCadSWIG: [geometry and parity](issues/geometry-and-parity.md).
- Exact Thor connector/population: [interface](domains/thor-interface.md).
- Repeatable release checks: [release playbook](playbooks/release.md).

- Valid CAD but non-watertight STL at boss joins: [tangent contact lesson](inbox/2026-10-26-tangent-boss-mesh.md).
- In-memory preview disagrees with exported STEP placement: [readback review lesson](inbox/2026-10-26-review-export-readbacks.md).
- Local and clean-checkout release ZIPs differ: [manifest allowlist](inbox/2026-10-26-release-manifest-allowlist.md).
- GitHub shows a folder index instead of the project overview: [README precedence](inbox/2026-10-26-github-readme-precedence.md).
- Clean DRC but separated CAN lines or interrupted return copper: [route geometry and return-plane audit](inbox/2026-10-26-can-routing-is-not-connectivity.md).
- Collision checks pass but PCB import reverses handedness: [proper PCB STEP transform](inbox/2026-10-26-preserve-pcb-handedness.md).
- Zone-to-zone ground ratsnest despite vias touching both layers: [ground island bridge](inbox/2026-10-26-ground-islands-need-a-real-bridge.md).
- Current generic report marked stale, or changed geometry still shows PASS: [report evidence formats](inbox/2026-10-26-report-freshness-formats.md).
- Prototype taps remain disconnected after routing, raw GPIO is unusable in Linux, or insert supports have thin post-cut webs: [prototype power and support checks](inbox/2026-10-26-prototype-power-and-supports.md).

- Reports pass locally but fail the merged toolkit: [all severities and default-disabled checks](inbox/2026-10-26-complete-kicad-evidence.md).

- Mounting ears pass minimum-web checks but look too narrow or fail to support corners: [four broad corner mounts](inbox/2026-10-27-four-corner-mounts.md).
- Engraving looks clear in a render but uses tiny lettering, or a successful slice has incorrect inherited settings: [nozzle-scale lid review](inbox/2026-10-27-printable-lid-markings.md).
